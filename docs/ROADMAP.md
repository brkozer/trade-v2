# Evidence-driven roadmap

| Milestone | Deliverable and exit condition |
| --- | --- |
| M0 — Unified kernel | Canonical contracts, strict modes, public market data, evidence, risk, accounting and execution invariants pass tests. |
| M1 — Alpha Factory V1 | Multiple mechanisms, recorded search budgets, chronological cost-aware evaluation and reproducible rejection/ranking. |
| M2 — Prospective shadow candidates | Only independent surviving candidates enter frozen prospective checkpoints; no survivors means further preregistered search first. |
| M3 — Microstructure and execution alpha | Prospective L2/publicTrade integrity, measured fill and adverse-selection calibration, paired execution studies. |
| M4 — Conditional/ML selection | Point-in-time regime/ranking models only if adequate data and independent net-economic gains justify them. |
| M5 — Paper execution acceptance | Surviving alpha tested across realistic accounting, partial fills, protection, lifecycle and restart. |
| M6 — Final/prospective acceptance | Frozen candidate, fresh data, declared fixed-horizon scientific acceptance. |
| M7 — Bybit testnet | Explicitly authorized authenticated lifecycle and operational verification. |
| M8 — Governed live canary | Separate operator approval after scientific and operational requirements. Not authorized by this build. |

An unsupported or failed gate stays closed. Negative research is useful evidence and does
not justify weakening risk, relabelling reused data, or promoting the highest-ranked loser.
