# Future evidence and optional improvements

The current product preserves negative historical findings and can collect new
public evidence. No candidate is promoted. The following are future activities,
not a way to relabel rejected historical results:

- Accumulate a fresh prospective orderbook/trade window to calibrate execution
  and test preregistered microstructure hypotheses.
- If a new economically distinct candidate passes chronological net-cost gates,
  freeze prospective shadow and paper checkpoints before observing outcomes.
- With dedicated account authorization, run a separately reviewed testnet
  acceptance program covering recovery, partial fills, protection and reconciliation.
- Consider distributed account authority if multi-host privileged execution is
  needed; the current lock is deliberately local only.
- Consider governed live canary only after all scientific and operational gates
  in `LIVE_ACCEPTANCE.md` pass. Live remains hard disabled in this release.
